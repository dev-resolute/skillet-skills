# HubSpot

Read-side coverage of the HubSpot CRM API: list and get contacts, companies,
deals, tickets, products, and line items; list and get owners; list and get
pipelines and pipeline stages (per object type); list properties per object
type; and list the associations between one object and another object type.

Auth: private app access token as a Bearer header.
